Forge is the Good Ancestor Foundation's open toolkit for running model work on hardware we own: training, fine-tuning, quantization and model surgery on a shared GPU fleet, operated by AI agents and governed by people.

Why it exists

Running models on a real fleet is full of small, error-prone decisions: which CUDA and PyTorch stack fits which GPU generation, which datasets are cleared for use, whether a GPU is free or serving live traffic, whether a job saved a checkpoint before it stopped.

Forge turns each of those into a small, tested command with machine-readable output. An agent can operate the fleet without improvising, and every consequential step leaves a record a person can audit.

What's in it

An environment for each GPU class
Ada, Blackwell, datacenter and ROCm machines each get their own pinned lockfile, so the software always matches the hardware. A weekly job proposes updates as a pull request, and a person smoke-tests them on the real GPU before merging.
A governed dataset archive
One manifest lists every dataset with its source, license, size and storage path. Fetches are refused for anything unapproved, over the size cap, or of unknown size.
Runs that share the fleet safely
Every job holds a lease with a heartbeat, so two agents never fight over one GPU, and touching a machine that serves production raises a loud warning. Runs can resume, and each one writes a signed record of exactly what happened.
Recipes for common jobs
Declarative YAML for each kind of work, pinned to the environment it needs.
  • LoRA SFT
  • DPO
  • GRPO
  • AWQ
  • GGUF
  • NVFP4
  • abliteration
  • expert pruning

The human's job is small on purpose

  • Review the pull requests. Agents propose changes. None merge themselves.
  • Decide what's approved. The approved: flags belong to people.

Everything else is mechanical, tested and automated. Approval gates are final: a refused fetch stays refused until a person changes the manifest, and agents don't work around it.

Failures that say what they are

Every Forge command exits with a code that tells a person or an agent what kind of stop it was, so a refusal is never mistaken for a crash.

2RefusedA gate said no. Wait for a human decision; don't retry.
3Job failedThe work itself broke. Read the run record.
4UnreachableInfrastructure didn't answer. Safe to retry later.
75CheckpointedPaused cleanly with progress saved. Resume it.

Run it yourself

$ git clone https://github.com/GoodAncestor/forge
$ cd forge && uv sync
$ uv run forge data list      # what exists, what's approved
$ uv run forge lease status   # who holds which GPU

Add --json to any command for machine-readable output; that's how agents drive it. Interfaces may change. The safety principles will not.

Who runs it

The Good Ancestor Foundation uses Forge in production on its own fleet. You can see that fleet live on our status page. We publish Forge to help others stand up local, sovereign AI infrastructure of their own.
